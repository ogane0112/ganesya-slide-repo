# 判断するAI? Jevの正体

はやく、やすく、いいかんじに判断してくれるAI

2026-09-28

---

# Jevってなに?

- TypeSafe AIが**2026年9月15日**に早期提供を始めたAI
- 文章は書かない。**判断だけ**をする専用モデル
- 答えは「選択肢」「段階」「確率」のような**型の決まった値**

<div class="point">

ひとことで言うと、**はやく・やすく・いいかんじに**判断してくれるAI。

</div>

---

# 聞き方は3つの型

| 型 | 聞き方 | 返ってくるもの |
| --- | --- | --- |
| Choice | どれに当てはまる? | 選んだ選択肢 |
| Score | 何段階のどれくらい? | 段階(小数の期待値) |
| Noul | これは正しい? | 正しい確率 |

<div class="note">

判定したい文章(State)1つに、質問をまとめていくつも投げられる。

</div>

---

# 数字で見るJev

- 応答は **70〜500ミリ秒**
- 料金は入力100万トークンで **0.042ドル**、出力は**無料**
- 1リクエストは64kトークンまで

<div class="warn">

早期提供中なので、料金・制限はこれから変わるかもしれない。

</div>

---

# 例: チャットボットの問い合わせ振り分け

| 問い合わせ | Jevの答え(Choice) | 回す先 |
| --- | --- | --- |
| 請求額が先月と違う | 料金 | 料金の窓口 |
| ログインできない | 技術 | 技術サポート |
| 営業時間を知りたい | その他 | 総合窓口 |

<div class="point">

Jevは振り分け先を**決めるだけ**。返事を書くのは各窓口(人や別のAI)。

</div>

---

# なぜ分類にJevが向いている?

- ふつうのAIで分類すると、考える過程や文章も出すので**時間と料金がかさむ**
- 組み込み用には安さで選ばれるAI(Geminiなど)も多いが、それでも出力には料金がかかる
- Jevは答えが短く、出力は無料。**呼ぶ回数が多い分類**ほど差が出る

<div class="point">

Claude CodeやCodexの長い思考を見ると分かりやすい。
「どれに当たるか決めるだけ」に、あそこまでの思考はいらない。

</div>

---

# 既存のAIとの大きな違い

| | Jev | 既存のAI |
| --- | --- | --- |
| 答え方 | 決定論的 | 非決定論的 |
| 答えの形 | 型の決まった値 | 自由な文章 |
| 得意なこと | 判断・分類・採点 | 文章・コードを書く |

<div class="note">

同じ入力なら同じ答えが返るので、結果を**キャッシュ**しやすく、テストもしやすい。

</div>

---

# 苦手なこともある

- 文章を書く(修正案を作るなど)
- 計算や、日付の前後を比べる

<div class="summary">

- 判断 → Jev
- 文章 → 人(+Claude Codeなどの生成AI)
- 数値のチェック → ふつうのプログラム

</div>

---

# 機械チェックとJevの使い分け

| 機械チェック(プログラム) | Jev |
| --- | --- |
| 文字のはみ出し・フォントサイズ | 技術的な誤りがありそうか |
| コードの横はみ出し | 見出しと本文が合っているか |
| 決まったルールで判定できること | 内容を読まないと判定できないこと |

# 実例: このスライドのリポジトリ

- 原稿は **Marp**(Markdownでスライドを書く)
- `npm run check` で2つを同時にチェック
  - レイアウト検査(Playwrightで描画して数える)
  - Jevで内容を判定(誤り・情報量・個人情報など)
- 引っかかったスライドは原文付きでレポートに出る

<div class="note">

直すのはレポートを見ながら、人とClaude Codeの対話で行う。

</div>

# まとめ

<div class="summary">

- Jevは文章を書かず、**判断だけ**をするAI
- 答えは型の決まった値(選択肢・段階・確率)で、はやくてやすい
- 分類・採点のように**回数の多い判断**に向いている
- 文章は人と生成AI、数値はプログラム、判断はJevで分担する

</div>
